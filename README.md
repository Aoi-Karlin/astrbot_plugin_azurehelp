一个土豆帮助触发器。

`/help` 会把「帮助图 + 网站教程（https://azure712.space/bothelp）」打包成一条**合并转发**发出来；
在不支持合并转发的平台上自动退化为逐条发送。

- 帮助图：`file/help_page.png`（不存在则跳过该节点）
- 教程文本：`file/tutorial.txt`（网站教程的离线快照，站点更新后改这个文件即可）
  - 已收录：签到（无前缀，50 + 10n）、收藏集抽卡（`/抽卡` `/卡池` `/换池` `/图鉴` `/获取卡` `/抽卡帮助`）、管理员指令（`/发积分` `/发卡`）、接歌词、点歌 / 副歌、赞我、好感度、help

采用WTFPLv2许可证。
